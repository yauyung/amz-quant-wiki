# AMZ Quant Wiki

> 惊天骇地的量化 · 知识库
> 
> AI + Quantitative Trading 双主线 Karpathy-style Wiki
> Obsidian 兼容 · Git 同步

## 两条主线

- **AI** — LLM、Agent 架构、训练/推理、对齐
- **Quant** — 因子研究、策略、风控、回测

## 结构

| 目录 | 内容 |
|------|------|
| `原始资料/` | 论文、文章（只读，不修改） |
| `AI/` | AI 线 Wiki 页面 |
| `Quant/` | Quant 线 Wiki 页面 |
| `交叉/` | AI×Quant 交叉对比 |
| `实体/` | 人物、公司、工具 |
| `概念/` | 概念页 |
| `Attachments/` | 图片附件 |

## 使用方式

```bash
git clone git@github.com:yauyung/amz-quant-wiki.git
# 用 Obsidian 打开此文件夹作为 Vault
```

Agent 负责写 Wiki，人负责策划来源和提问。
