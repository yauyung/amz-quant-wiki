## 论文1：KTD-FIN — 从知道到做到
### arXiv:2605.28359 | 京东 · 清华 · FinStep | 2026.05.27

**一句话**：LLM 交易 agent 的"能力幻觉"——看似赚钱，实则靠因子暴露，选股 alpha 接近零甚至为负。

### 核心方法

1. **四层数据掩码协议**：逐步匿名化股票代码和日期
   - Bright → Stock-blind → Date-blind → Blinded
   - 杜绝 LLM 用预训练记忆替代推理

2. **Barra 风格归因**：把收益拆成三块
   - 市场收益（β）+ 风格因子暴露 + 选股 alpha
   - 发现 LLM agent 收益 = 前两项，选股 alpha 约 0

3. **实验**：CSI300 上跑 10 个前沿 LLM，Qlib 引擎，A 股环境（T+1，涨跌停）

### 可复现性

| 要素 | 状态 |
|---|---|
| 代码 | 承诺公开，URL 待发布 |
| 数据 | Qlib + CSI300 OHLCV，可获得 |
| 框架 | Qlib（微软开源 AI 量化平台） |
| 适配 Freqtrade | 中等（方法论可移植） |

### 💡 我们能直接用的

- **掩码协议** → 加进 Freqtrade 回测，消除 LLM 数据窥探
- **Barra 归因** → 分析现有策略收益来源，看清是运气还是实力

## 论文2：News-Aware Direct Reinforcement Trading
### arXiv:2510.19173 | 中国科学院大学 | 2025.10.22

**一句话**：LLM 读新闻提取情感分 + 强化学习直接下单，在 BTC 上跑赢基准。

### 核心方法

1. **情感提取**：Gemini-2.5-flash → 新闻 → 情感得分 + 风险得分
2. **序列编码**：LSTM 或 Transformer 处理 OHLCV + 情感向量
3. **RL 决策**：
   - DDQN（off-policy）或 GRPO（DeepSeek 提出的 PPO 变体，无需 critic）
   - 三选一动作：做多 / 做空 / 持有
4. **标的数据**：BTC/USDT 1 分钟 K 线，2019-2024

### 可复现性

| 要素 | 状态 |
|---|---|
| 代码 | ❌ 未公开 |
| 数据 | Binance OHLCV + HuggingFace Bitcoin News 数据集 |
| LLM 依赖 | Gemini API（可替换） |
| 适配 Freqtrade | ⭐ 高 — 加密 + OHLCV + 相同技术栈 |

### 💡 实施路线

1. 先实现 DDQN + LSTM baseline
2. 验证后再考虑 GRPO（更新，实现更复杂）
3. 情感提取可先用本地小模型替代 Gemini，零成本

## 论文3：TradeArena — LLM 交易 Agent 的表征退化
### arXiv:2605.28850 | Virginia Tech | 2026.05.16

**一句话**：LLM agent 在亏损前，内部表征已经开始偏离——可以提前预警。

### 核心方法

1. **表征监控**：LLM 推理过程中的 plan embedding 向量
2. **退化检测**：回撤发生前，embedding 有效秩(effective rank)收缩
3. **检测精度**：融合 plan + risk 表征，准确率 0.807
4. **压力测试**：OHLCV 噪声注入 20%、虚假审计报告、相关性盲点

### 可复现性

| 要素 | 状态 |
|---|---|
| 代码 | ⚠️ 提到 public repo 但 URL 未找到 |
| 模型依赖 | Poe API（GPT-5.5, Gemini 3.1 Pro 闭源） |
| 适配 Freqtrade | 低 — 独立框架 |

### 💡 长期价值

- 可作为现有系统的**诊断层**，监视 agent 推理质量
- 不是盈利策略，是风控工具
